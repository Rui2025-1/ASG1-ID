# ASG1-ID

Divergent Divers is a fictional multi-page website created to showcase a clean, interactive, and user-friendly diving school.
The site includes microinteractions, scroll animations, interactive navigation, and responsive design suitable for modern browsers and devices.

This website is designed for:

New divers curious about starting their diving journey

Intermediate divers who want guided dive trips, equipment, or professional instruction

Parents or guardians researching safe diving schools for younger divers

Tourists visiting coastal regions and looking for dive experiences

Hobbyists seeking reliable instructors, diving information, or certification

Anyone interested in learning more about scuba diving in a clear, friendly format.

The main purpose of the site is to:

Provide information about diving courses, guided trips, and equipment

Build trust through clear explanations and simple navigation

Encourage visitors to reach out, ask questions, or book a session.

Users benefit from:

Simple, clear navigation across Home, Services, About, and Contact pages

Friendly, human-centered writing that reduces intimidation for new divers

Quick access to key details such as services, locations, and contact info

Interactive microinteractions and animations that improve user experience

Mobile, tablet, and desktop compatibility with consistent design

Realistic structure similar to industry websites, useful for portfolios or assignments.
🐠 What the Website Is Catering For?

The website caters for:

✔ New Diver Training

Explaining beginner courses in a gentle, approachable way
(aimed at people with zero experience).

✔ Certified Diver Expansion

Offering advanced or guided dives for those with existing certifications.

✔ Tourist & Casual Visitors

Providing contact details, trip information, and a clear overview of activities.
